# Лендінг «Накопичувальне страхування життя»

Односторінковий сайт з інтерактивним калькулятором накопичення.
Форма заявки надсилає сповіщення у Telegram.

## Що всередині
- `index.html` — сам лендінг (усе в одному файлі: HTML + CSS + JS)
- `api/lead.js` — serverless-функція: приймає заявку і шле її в Telegram
- `.gitignore`

---

## Крок 1. Створити Telegram-бота і дізнатися свій chat_id

1. У Telegram відкрий **@BotFather** → команда `/newbot` → задай імʼя й нік бота.
   BotFather дасть **токен** виду `123456789:AAE...` — збережи його.
2. Знайди свого бота в пошуку і натисни **Start** (надішли йому будь-яке «привіт»).
3. Дізнайся свій **chat_id**: відкрий у браузері
   `https://api.telegram.org/bot<ТВІЙ_ТОКЕН>/getUpdates`
   (замість `<ТВІЙ_ТОКЕН>` встав токен). У відповіді знайди `"chat":{"id": ... }` — це твій chat_id.
   Якщо порожньо — ще раз напиши боту «привіт» і онови сторінку.

> Хочеш отримувати заявки в спільний чат/групу — додай бота в групу і візьми chat_id групи (він буде відʼємним, напр. `-100...`).

**Варіант А — через сайт GitHub (без термінала):**
1. Створи новий репозиторій на https://github.com/new (напр. `money-insurance-landing`).
2. На сторінці репозиторію → **Add file → Upload files** → перетягни `index.html`, папку `api` та `.gitignore` → **Commit**.

## Крок 3. Задеплоїти на Vercel (щоб працювала Telegram-форма)

GitHub Pages не вміє виконувати серверний код, тому форму піднімаємо на **Vercel** (безкоштовно) — він бере код прямо з твого GitHub.

1. Зайди на https://vercel.com → увійди через GitHub.
2. **Add New → Project** → обери свій репозиторій → **Import** → **Deploy**.
3. Після деплою відкрий **Project → Settings → Environment Variables** і додай змінні:
   - `TELEGRAM_BOT_TOKEN` = токен бота з Кроку 1
   - `TELEGRAM_CHAT_ID` = твій chat_id з Кроку 1
   - `LEAD_SOURCE` *(необовʼязково)* = підпис джерела в повідомленні, напр. `Накопичувальне страхування`
4. Натисни **Redeploy** (щоб змінні підхопились).

Готово. Vercel дасть посилання виду `https://твій-проєкт.vercel.app` — це робочий сайт із формою, що шле заявки в Telegram.

### Який вигляд має сповіщення в Telegram
```
⚡ Нова заявка на консультацію (Накопичувальне страхування життя) ⚡

👤 Імʼя: Михайло
📞 Телефон: +380 68 684 56 60
🛠 Вибрана послуга: Захист сім'ї
📅 Зручний час для звʼязку: 20.09.2026 09:00 – 12:00
📝 Коментар: Цікавить накопичення на навчання дитини

🕒 Відправлено: 18.09.2026 10:15
```
Поля «послуга», «зручний час» і «коментар» у формі — щоб заявка одразу була інформативна. Обовʼязкові лише імʼя й телефон; решта додається в повідомлення, якщо клієнт заповнив.

## Налаштування «під себе»
- **Дохідність калькулятора:** у `index.html` знайди `var RATE = 0.07;` — це 7% річних (складний відсоток). Зміни за потреби.
- **Контакти:** телефон і адреса вже проставлені (Ужгород, вул. Швабська, 12б; +380 99 552 42 57).
- **Відгуки, соцмережі:** заміни на реальні (позначено в коментарі зверху `index.html`).
- **Назва/логотип, email, ліцензія:** свідомо прибрані — додаси, коли готуватимеш під конкретну страхову.

## Порада щодо реклами фінпослуг
Прогнозована дохідність у калькуляторі — орієнтовна. Диклеймери під калькулятором і в підвалі це закривають, але перед запуском реклами звір формулювання з комплаєнсом обраної страхової.
